# Ph.D. defense: Spatial Intelligence for Smart Radio Environments

Hieu T. Le, Texas A&M University, December 2026.

Open the presentation: **https://hieutrungle.github.io/phd-defense/**

- Arrow keys, Space, or the light **‹ ›** arrows at the screen edges: next / previous slide
- **☰›** tab (left edge): contents bar with every part and slide, a search box, click to jump
- **G**: go to any slide (type a number or words)
- **F** or the ⛶ button (bottom right): full screen
- **Esc** / **O** or the ▦ button (left of ⛶): slide overview with thumbnails of every slide; click one to jump. In the overview, a slider below the thumbnails scrolls through all slides (drag it, click a part number 1–7/B, or use the mouse wheel / trackpad swipe)
- Animations: hover to show play/pause and a step slider; **K** play/pause, **[** / **]** step

Best viewed in Chrome or Edge. The site is fully static (reveal.js); no data is collected.

## What is in this repository

This repository is the complete working copy of the deck: clone it on any computer to present, edit, rebuild and publish.

| Path | Contents |
|---|---|
| [`speaker_notes.md`](speaker_notes.md) | Timing table and full speaker notes for every slide (generated by `build.py`; in the repository only, not on the website) |
| `index.html` | The full deck **with** speaker notes, for presenting offline (generated by `build.py`) |
| `src/` | Slide sources: `src/sections/*.html` (one file per part; backups in `9x_*.html`), `src/head.html`, `src/tail.html` |
| `assets/` | Styles (`assets/css/theme.css`), deck runtime and animations (`assets/js/`), all figures (`assets/img/`, including ones not used yet) |
| `media/`, `vendor/` | Simulation videos; reveal.js, KaTeX and fonts (no internet needed) |
| `build.py` | Assembles `index.html` and `speaker_notes.md` from `src/`; fails if the talk leaves the 40–45 min window or a note exceeds 140 words per minute |
| `tools/` | `publish.py` (website + push), `make_pdf.py` (backup PDF), `shoot.js` (slide screenshots with console/overflow report) and other QA scripts |
| [`docs/`](docs/) | The public website, generated by `tools/publish.py` (speaker notes removed). GitHub Pages serves only this folder |
| [`CHANGES.md`](CHANGES.md) | Change log of slide edits |

## Working on another computer

```bash
git clone https://github.com/hieutrungle/phd-defense.git
cd phd-defense
# edit src/sections/*.html (slides and <aside class="notes"> speaker notes) or assets/
python build.py                 # Python 3, standard library only
# preview: open index.html in Chrome (press S for the speaker view)
python tools/publish.py         # rebuild docs/, commit everything, push; the website updates in about a minute
```

Use `python tools/publish.py --no-push` to rebuild `docs/` without committing, and `-m "message"` for a custom commit message. Ordinary `git pull` / `git push` work as usual; always pull before editing on a different computer.

Optional QA tools (screenshots, backup PDF) need Node.js and a headless Chrome:

```bash
npm install
npx @puppeteer/browsers install chrome-headless-shell@stable   # prints the path of the downloaded binary
export CHROME_PATH="<that path>"     # default if unset: .browsers/chrome-headless-shell-linux64/chrome-headless-shell
node tools/shoot.js shots --ids mappo,div-hmarl     # PNGs + shots/_report.txt (console errors, overflow)
pip install pillow && python tools/make_pdf.py      # defense_slides_html_backup.pdf (all slides)
```

`node_modules/`, `.browsers/`, screenshots, PDFs and zips are ignored by git.

## Presenting offline

1. Open `index.html` (repository root) in **Google Chrome or Microsoft Edge**. No internet connection is needed.
2. Press **F** for full screen. Slides are designed at 1280×720 (16:9) and scale to the projector.
3. Press **S** for the speaker view (current/next slide, notes with timing windows, timer). Allow pop-ups if the browser blocks it.
4. → / Space next (fragments and animation steps first), ← back, **B** or **.** black screen; **G** jumps to any slide by number or words.
5. The on-screen arrows and the contents tab appear when the mouse moves and fade out after 2.5 s, so they are invisible while you present with a clicker or the keyboard.

Main talk: 60 timed slides, 40.25 min of speaker notes (Intro 12.75, Learning 15.50, Placement 12.00 min), followed by 27 backup slides.
