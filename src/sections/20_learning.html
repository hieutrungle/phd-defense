MA-MDP: each agent moves the focal point of one segment

Array partitioned into $L$ disjoint segments $\mathcal{T}_l$; agent $l$ controls focal point $f_{l,t}\in\mathbb{R}^3$.

  • State: $s_t=[u_{1,t},\dots,u_{K,t},\,r_{1,t},\dots,r_{L,t},\,f_{1,t},\dots,f_{L,t}]$user positions, segment centers, focal points
  • Local observation: $o_{l,t}=[u_{b_l,t},\,r_{l,t},\,f_{l,t}]$; assigned user $b_l$ fixed in advance
  • Action: $a_{l,t}\in\mathbb{R}^3$, $\|a_{l,t}\|_\infty\le\delta_{\max}$, $\;f_{l,t+1}=f_{l,t}+a_{l,t}$
  • Shared reward: $R(s_t,a_t)=\frac{1}{K}\sum_{k=1}^{K}P_{r,k}(s_t,a_t)$ (RSSI)
  • Focal points clipped to $\mathcal{F}_l$, angles to $\pm30^\circ$: every action feasible

Run time: positions only; training: received power as the reward. No pilot-based CSI estimation.

Answers the geometric limits:
servo limits → clipped actions
alignment → received-power reward
several users → one agent per segment

Multi-user control becomes a cooperative multi-agent MDP. The array is split into L disjoint segments, three here, and each agent controls one segment's focal point.

The global state holds the user positions, the fixed segment centers, and the current focal points. Each agent observes only its own segment: the position of its assigned user, its center, and its focal point. The assigned user is fixed in advance; this matters later.

The action is a bounded focal-point displacement, so the tiles move smoothly.

All agents share one reward, the mean received power of the users. Power is used only in training, so at run time the agents need positions only.

Focal points and tile angles are clipped to their limits, so every action is feasible. This is how learning answers the geometric limits: it acts within servo limits, optimizes received power, and serves several users.

The abstraction cuts the control dimension from two angles per tile, 126 angles for 63 tiles, to three coordinates per segment, 9 for three segments: fourteen times fewer.

Training with MAPPO under CTDE

  • MAPPO: multi-agent proximal policy optimization
  • CTDE (centralized training with decentralized execution) mitigates non-stationarity: global critic in training, local actors at deployment
  • Execution: each actor uses only its local observation; no inter-agent communication
  • Actor and critic: small MLPs, Adam optimizer (settings in backup)
$L(\psi_l,\xi)=L^{\mathrm{CLIP}}(\psi_l)-c_1\,L^{\mathrm{VF}}(\xi)+c_2\,H[\pi_{\psi_l}](o_t^l)$
Clipped surrogate
$L^{\mathrm{CLIP}}(\psi_l)=\mathbb{E}_t\big[\min\big(\rho_t^l\,\mathrm{Adv}_t^l,\ \mathrm{clip}(\rho_t^l,1{-}\epsilon,1{+}\epsilon)\,\mathrm{Adv}_t^l\big)\big]$
ratio $\rho_t^l=\pi_{\psi_l}/\pi_{\psi_{\mathrm{old},l}}$; advantage $\mathrm{Adv}_t^l=\mathrm{Adv}(s_{\mathrm{global},t},a_t^l)$ from the critic; clipping limits each actor update
Value loss
$L^{\mathrm{VF}}(\xi)=\mathbb{E}_t\big[(V_\xi(s_{\mathrm{global},t})-V_{\mathrm{target},t})^2\big]$
mean squared error of the centralized critic to the empirical return
Entropy
$H[\pi_{\psi_l}](o_t^l)=-\mathbb{E}\big[\log\pi_{\psi_l}(a\mid o_t^l)\big]$
bonus that keeps exploring focal points

The agents are trained with MAPPO, multi-agent proximal policy optimization, under centralized training with decentralized execution, which addresses non-stationarity.

In training, the centralized critic sees the global state and reward and supplies advantages. At deployment the critic is discarded; each actor maps its local observation to a focal-point move, with no communication.

The objective has three terms. The clipped surrogate takes the smaller of the ratio-weighted advantage and its clipped version, so one batch cannot move a policy far. The value loss fits the critic to the observed return, and the entropy bonus keeps the agents exploring focal points.

From fixed assignment to learned allocation

Two corner arrays: a user can be served by segments with very different geometry, so the assignment now matters.

Serving $K$ users with $L$ segments needs two coupled decisions:

  1. Which user should each segment serve?
    discrete, couples the segments, should change only when the geometry changes
  2. Where should each segment focus?
    continuous, per segment, rate-limited by servo actuation
Why the assignment is hard
  • $|\mathcal{B}|=K^L$: 16 assignments for $K=2$, 256 for $K=4$ ($L=4$)
  • A poor assignment leaves a user served only by residual multipath
  • Servo limits: non-convex reachable set
  • State: noisy position estimates; no pilot-based CSI estimation
Make the user-to-segment assignment a learned decision on its own, slower timescale.

Now two corner arrays serve the room, so the partition matters.

There are two decisions: which user each segment serves, discrete and coupled; and where each segment focuses, continuous and servo-limited. The assignment space grows as K to the power L: with four users and four segments, 256 options. So the assignment becomes a learned decision on its own, slower timescale.

Two-timescale hierarchy: slow allocation, fast focusing

slot = one control step; drawn for $T=4$, experiments use $T=10$

  • Allocator: global state, decision held for the window
  • Segments: masked local state, no inter-segment communication
  • Critics in training only; deployment runs $\pi_H$ and $\{\pi_{\psi_l}\}$
  • Run time: positions only; training: received power as the reward

The hierarchy has two levels. At the top, a centralized allocator reads the global state: all user positions, segment centroids and current focal points. Every T slots, ten in the experiments, it emits an assignment vector, one user index per segment, which is broadcast and held for the window.

Below, one agent per segment moves its focal point every slot. It sees only nine numbers: its assigned user's position, its own centroid and its focal point. Segments do not communicate.

At run time both levels see positions only; power is only the training reward. The timeline is drawn with T of four; experiments use ten.

HMA-MDP: one objective, a reward for each timescale

High level: allocation (every $T$ slots)
State $s_H=\{u_{1:K},\,r_{1:L},\,f_{1:L}\}$, action $b\in\mathcal{B}$
Reward: concave, every user counts $$R_{\mathrm{sys}}=\frac1K\sum_{k=1}^{K}\ln\bigl(1+[\tilde P_k(t)]^+\bigr)$$ Trained on macro-steps: the discounted return inside each window
Low level: focal points (every slot)
Masked state $s_{L,l}=\{u_{b_l},\,r_l,\,f_l\}$, $\|a_{l,t}\|_\infty\le\delta_{\max}$
Reward: assigned user's power + progress $$R_l(t)=\frac{1}{P_{\mathrm{sc}}}\Bigl[\tilde P_{b_l}(t)+\bigl(\tilde P_{b_l}(t)-\tilde P_{b_l}(t{-}1)\bigr)\Bigr]$$ Second term: potential-based shaping ($\Phi=\tilde P_{b_l}$)

Shared objective: $\max\ \mathbb{E}\bigl[\sum_{t}\gamma^{t}R_{\mathrm{sys}}(s(t),b(t))\bigr]$ s.t. $b(t)\in\mathcal{B}$ at $t\in\{0,T,2T,\dots\}$, $f_l(t)\in\mathcal{F}_l$, servo limits.

$\tilde P_k$: shifted received power (dBm); $P_{\mathrm{sc}}$: scale (backup). Unlike flat MARL (clipping), a move that would push any tile past its limit is rejected.

Both levels serve one discounted objective, each with a reward suited to its decision.

The allocator's reward is a log utility averaged over all users. Unlike flat MARL's mean, one strong user cannot mask an unserved one, and a decibel gained by a weak user is worth more. Because its decision is held for T slots, it is trained on macro-steps: the discounted return inside each window.

Each segment is rewarded with its assigned user's shifted power plus a progress term, potential-based shaping. One change from flat MARL: a move that would push any tile past its limit is rejected rather than clipped.

Training under CTDE, with a geometric warm start

Low level: MAPPO

  • $L$ local actors $\pi_{\psi_l}(a_l\mid s_{L,l})$
  • One shared centralized critic $V_\xi(s_{\mathrm{global}},l)$, $s_{\mathrm{global}}=s_H$
  • GAE, clipped surrogate objective

High level: PPO on macro-steps

  • Own critic $V_{\xi_H}$ on the macro timescale
  • One advantage estimate per allocation
  • Factorized head: $LK$ logits instead of $K^L$ joint scores

One axis of prior strength:
$\alpha\equiv0$: HMARL-NC  |  warm start: HMARL-C
$\alpha\to\infty$: Compat-only ($b_l=\arg\max_k C_{kl}$)

Compatibility prior (positions only)
$$C_{kl}=\exp\!\Bigl(-\frac{\|u_k-r_l\|}{d_0}\Bigr)\cos\!\Bigl(\frac{\vartheta_{kl}}{2}\Bigr)$$ $$z'_{l,k}=z_{l,k}(s_H)+\alpha(t)\,C_{kl}$$ $\vartheta_{kl}$: bend angle at segment $l$ toward user $k$; $z$: allocator logits. $\alpha(t)>0$ only in an early warm-start phase, then $0$: objective unchanged

Segments train with MAPPO, as in flat MARL; the allocator uses PPO on the macro timescale with its own critic and a factorized head.

Exploring 256 assignments is slow, so early on a geometric prior, from positions only, is added to the logits, then switched off. Prior strength gives three variants: none, warm start, and infinite, a pure heuristic.
