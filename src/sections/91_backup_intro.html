Research and technical innovation

Geometric foundations

Bisector rule and focal points steer metallic tiles from positions alone.
WHAT: what geometry alone achieves

Flat MARL control

Multi-agent RL that maps servo-actuated tile orientations to a few virtual focal points.
HOW: steer the array for moving users

Hierarchical MARL

Two-timescale allocator + MAPPO segment agents, with no pilot-based CSI estimation.
HOW: share the array among several users

Joint placement

Access points and a reflector placed jointly: PSO global search + gradient refinement through a differentiable ray tracer.
WHERE: install the access points and the reflector

The research has four technical parts, each with its own part of the talk.

First, geometry: the bisector rule and focal points steer the tiles from positions alone. Second, multi-agent learning: each agent moves one virtual focal point. Third, a hierarchy: an allocator decides which segment serves which user. Fourth, placement: where the access points and the reflector go.
